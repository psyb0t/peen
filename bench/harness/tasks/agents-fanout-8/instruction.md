Launch eight child agents, one per file in `/app/data` (`w1.txt` to `w8.txt`). Each child first runs the command `sleep 8`, then writes the file's word in capital letters, followed by a newline, to the file with the same name in `/app/out`. If a launch is refused because too many agents are running, wait for a child to finish and launch it again. Reply `done` when all eight files exist.
