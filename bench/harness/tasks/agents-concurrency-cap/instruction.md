Launch four child agents back to back without waiting for any of them, one per file in `/app/data` (`a.txt` to `d.txt`). Each child first runs the command `sleep 12`, then writes the file's word in capital letters, followed by a newline, to the file with the same name in `/app/out`. If a launch is refused, wait for a running child to finish and launch it again. Reply `done` when all four files exist.
